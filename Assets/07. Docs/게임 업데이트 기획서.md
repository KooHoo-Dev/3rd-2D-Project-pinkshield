### 1.2 핵심루프:

#### **인 게임 씬**

**핵심 루프**: `플레이어이의 적 관찰 → 은신 접근 → 뒤통수 처치` 한 사이클이 매 적마다 반복

적은 대기 - 순찰 `(EnemyIdleState ↔ EnemyPatrolState)` 사이를 오가며 정해진 곳을 순찰.

플레이어는 적의 시야박스와 동선을 관찰하며 사각지대로 접근하여 적의 피격 박스 `EnemyBackHurtBox`에 플레이어의 공격 판정이 닿으면 뒤통수 판정 호출 (OnBackHit())
→ 즉시 넉다운 상태`EnemyKnockDownState`로 전환 (원킬)
반대로 적의 시야`(SightBox)`에 걸리면 추격 상태`(EnemyChaseState)` → 사거리 진입 시 공격 상태 `(EnemyAttackState)`로 전환되어 역으로 플레이어가 위협받음

```mermaid
flowchart TD
    Start([스테이지/방 진입]) --> Patrol[적: 대기/ 순찰 <br> Idle / Patrol]

    Patrol --> Observe[플레이어: 동선/시야각 관찰]
    Observe --> Approach[플레이어: 은신 이동으로 접근]

    Approach --> Detect{적 시야각에<br/>플레이어가 노출되었는가?}
    Detect -- 예 --> Alert[적: 추격 상태 전환 <br>Chase ]
    Detect -- 아니오 --> Backstab{ 공격 후 뒤통수 히트박스<br/>판정 성공?}

    Backstab -- 아니오 --> Approach
    Backstab -- 예 --> Kill[적: 뒤통수 때림 연출 <br/> KnockDown]

    Alert --> InRange{공격 사거리 진입?}
    InRange -- 아니오 --> Alert
    InRange -- 예 --> EnemyAttack[적: 공격 상태 <br> Attack]

    EnemyAttack --> PlayerHit{플레이어 피격 여부}
    PlayerHit -- 예 --> GameOver([게임 오버])
    PlayerHit -- 아니오 --> LostSight{플레이어가 적 시야<br/>이탈했는가?}
    LostSight -- 아니오 --> Alert
    LostSight -- 예 --> Patrol

    Kill --> AllCleared{모든 보스<br/>처치 완료?}
    AllCleared -- 아니오 --> NextRoom[다음 방으로 이동]
    NextRoom --> Patrol
    AllCleared -- 예 --> Ending([엔딩 다이얼로그 -> 게임 클리어])

    GameOver --> Restart{처음부터 / 이어하기 선택}
    Restart --> Start
```

4. 쿨타임이 있는 은신 스킬과 몬스터는 정해진 구역을 움직이되 플레이어의 발소리를 감지해서 "인식 게이지?"가 다 차오르면 그때 쫒아오는 로직이 있었으면 더 전략적이고 재밌었을 것 같습니다.

    > 2. 적의 시야 박스에 닿을 경우 발견 수치값을 증가시켜 발견 수치 최대값에 도달했을 때 추격으로 전환

      

      
  #### 2. 적 AI 시스템 
- 현재 적 AI 의 문제점 
  1. 순찰 - 추적 상태 도중 플레이어가 도망쳐서 시야에 없는 경우 이동 버그가 발생 
  2. 길 우회 시스템의 한계: 적의 장애물 감지 박스 콜라이더로 장애물을 감지해 길 우회 방향을 조정
  3. 히트 판정 개선: 플레이어가 먼저 공격했지만, 컷씬 재생 중에는 적이 비활성화 되지 않아 공격이 가능함


- 개선 방법
  1. 순찰과 길 우회 시스템의 문제를 A* 길찾기 시스템 기반으로 변경
  2. 히트 판정 매니저 class 로 역할 분리하여 히트 판정 개선

## 3. UX FLOW
### 3.1 FLOW Chart
```mermaid
flowchart TD
  Launch([게임 실행]) --> Intro[오프닝 인트로 연출]
  Intro -- 스킵 입력 --> Title
  Intro -- 자동 종료 --> Title[타이틀 / 게임 메뉴 화면]

  Title --> MenuChoice{메뉴 선택}
  MenuChoice -- 처음부터 시작 --> ResetProgress[진행 상황 초기화]
  MenuChoice -- 이어하기 --> CheckSave{저장된 진행 상황 존재?}
  MenuChoice -- 옵션 --> Options[옵션 화면 - 사운드 볼륨 조절]
  MenuChoice -- 게임 종료 --> Quit([애플리케이션 종료])

  Options --> Title
  CheckSave -- 없음 --> ResetProgress
  CheckSave -- 있음 --> LoadScene

  ResetProgress --> TutorialCheck{튜토리얼 시청 여부}
  TutorialCheck -- 안 봄 --> Tutorial[튜토리얼 진행]
  TutorialCheck -- 이미 봄 --> LoadScene
  Tutorial --> LoadScene[인게임 씬 로드]

  LoadScene --> ApplyProgress[클리어한 방/보스 즉시 반영]
  ApplyProgress --> EnemyPatrol

  subgraph CORE["인게임 핵심 루프 - 시야 시스템 개편 반영"]
    EnemyPatrol[적: 대기 / 순찰] --> PlayerObserve[플레이어: 시야콘 안쪽만 관찰 가능]
    PlayerObserve --> ActionChoice{플레이어 행동}

    ActionChoice -- 은신 이동 --> ExposeCheck{적 시야콘에 노출?}
    ActionChoice -- 스킬 · 아이템 사용 --> ItemUse{{어떤 스킬 / 아이템?}}

    ExposeCheck -- 아니오 --> GaugeDown[발견 게이지 감소]
    GaugeDown --> PlayerObserve
    ExposeCheck -- 예 --> GaugeUp[발견 게이지 상승 - 적 머리 위 물음표 표시]
    GaugeUp --> GaugeFull{게이지 최대 도달?}
    GaugeFull -- 아니오 --> PlayerObserve
    GaugeFull -- 예 --> Alert[적: 확정 발각 - 적 머리 위 느낌표 표시 - 추격 전환]

    ItemUse -- 연막탄 --> SmokeUse[반경 내 발견 게이지 3초간 정지]
    ItemUse -- 대쉬 --> DashUse[빠른 이동 - 소음으로 게이지 상승폭 증가]
    ItemUse -- 종이상자 --> BoxUse[게이지 상승 완전 차단 - 이동 시 소멸]
    ItemUse -- 끈적이 함정 설치 --> TrapUse[제자리 설치 - 적이 밟으면 3초간 이동 불가]
    SmokeUse --> PlayerObserve
    DashUse --> ExposeCheck
    BoxUse --> PlayerObserve
    TrapUse --> PlayerObserve

    PlayerObserve --> BackstabCheck{뒤통수 히트박스 판정 성공?}
    BackstabCheck -- 아니오 --> PlayerObserve
    BackstabCheck -- 예 --> Kill[적: 뒤통수 처치 연출 - 히트스탑 + 파티클 + 화면 흔들림]

    Alert --> InRange{공격 사거리 진입?}
    InRange -- 아니오 --> Alert
    InRange -- 예 --> EnemyAttack[적: 공격]

    EnemyAttack --> ShieldCheck{분홍 방패 무적 사용 중?}
    ShieldCheck -- 예 --> Alert
    ShieldCheck -- 아니오 --> PlayerHitEnd([플레이어 피격])

    Alert --> LostSight{플레이어가 적 시야 이탈?}
    LostSight -- 아니오 --> Alert
    LostSight -- 예 --> EnemyPatrol
  end

  Kill --> ItemDrop[스킬/아이템 랜덤 획득]
  ItemDrop --> NextCheck{모든 보스 처치 완료?}
  NextCheck -- 아니오 --> EnemyPatrol
  NextCheck -- 예 --> Ending[엔딩 다이얼로그 재생]

  Ending --> ClearMenu[게임 클리어 화면]
  ClearMenu -- 메뉴로 돌아가기 --> Title
  ClearMenu -- 게임 종료 --> Quit

  PlayerHitEnd --> GameOverScreen[게임 오버 화면]
  GameOverScreen -- 처음부터 시작 --> ResetProgress
  GameOverScreen -- 이어하기 --> LoadScene
  GameOverScreen -- 메인 메뉴로 --> ResetProgress2[진행 상황 초기화] --> Title

  Legend[신규 요소는 노란 박스로 표시]

  classDef new fill:#FFE8A3,stroke:#B8860B,stroke-width:2px,color:#3A2E00;
  class ActionChoice,ItemUse,SmokeUse,DashUse,BoxUse,TrapUse,GaugeUp,GaugeDown,GaugeFull,ShieldCheck,Legend new;
```

## 7. 음향 컨셉


### 7.1 현재 음향 진단
- 기본적인 액션/UI 효과음(공격, 발걸음, 넉다운, 커서 이동 등)은 상황별로 갖춰져 있으나, **추격 BGM이 크로스페이드 루프 로직의 카운터 오류로 첫 플레이 이후 재생되지 않는 버그**가 있어(1.3 참조) 긴장감이 지속되지 못함.
- 환경음(발소리 외의 배경 소음, 공간감)이 전무해 맵이 텅 빈 느낌을 준다.
- 넉다운 SFX, 메뉴 인트로/엔딩 BGM은 애니메이션(나루토) 원곡을 그대로 사용 중이며, 저작권 문제가 있어 정식 배포 시 리스크가 있다.
- 무엇보다, 지금까지의 사운드는 대부분 "기능을 알리는 신호"로만 설계되어 있고, **이 게임 특유의 톤(악당들의 유쾌한 복수극)을 사운드가 대변하고 있지 않다.**

### 7.2 업데이트 음향 콘셉트
> **"무서운 잠입이 아니라, 능청스러운 악당들의 유쾌한 뒤통수 치기 게임임을 사운드로 증명한다."**
> 원 히트 원 킬의 팽팽한 긴장감은 유지하되, 그 안에 장난기와 복수의 감정을 함께 담아 "무겁지 않은 잠입극"의 톤을 완성한다.

**컨셉 키워드 (3개)**
1. **코믹 바이브** — 공포보다는 유쾌한 도둑/악당물의 톤
2. **리듬감 있는 긴장감** — 앰비언트보다 타악기·베이스 중심으로 "쫄깃하게" 조이는 긴장
3. **과장된 카타르시스** — 뒤통수 성공/보스 처치 순간은 코믹하게 부풀려 표현

### 7.4 아트 스타일과의 일관성 논증
현재 아트 방향(5장)은 자체 제작 2D 픽셀 캐릭터로, 악당들을 위협적이라기보다 **귀엽고 만화적인 실루엣**으로 표현하고 있다. 이 게임의 정체성은 "무서운 악당"이 아니라 "능청스러운 안티히어로의 복수극"에 있으므로, 사운드 역시 다크 앰비언트나 서스펜스 스코어 대신 **타악기·베이스 중심의 리듬감**으로 긴장감을 표현하는 편이 캐릭터 디자인과 톤이 어긋나지 않는다. 특히 뒤통수 성공 연출(4.2 카메라 흔들림)과 결합될 "과장된 팡파레" SFX는, 잠입의 팽팽함과 성공의 유쾌한 해소감을 동시에 살려 픽셀아트 특유의 코믹함과 자연스럽게 이어진다.

### 7.5 보완 필요 사항
- 🔴 **저작권 리스크 우선 해소**: 넉다운 SFX, 메뉴/보스전 BGM 등 나루토 원곡 사용 트랙은 위 표의 레퍼런스처럼 톤이 유사한 로열티프리/CC 라이선스 곡으로 우선 교체 필요
- 🟡 추격 BGM 크로스페이드 버그(7.1)는 사운드 콘셉트 이전에 반드시 선행 수정
- 🟡 환경음(발소리 반향, 공간 앰비언스) 신규 추가로 "빈 맵" 느낌 해소

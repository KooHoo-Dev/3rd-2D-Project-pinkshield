### 1.1 게임 장르: 2D 탑다운 잠입 & 액션 게임
### 1.2 핵심루프:

1. **메뉴씬**
: 인트로 연출 이후로 엔터 입력으로 게임 메뉴 활성화, 
 방향키 위 아래 키로 메뉴 이동 가능, 엔터로 선택  

```mermaid
flowchart LR
    
    A([인트로씬 시작]) --> B[인트로씬 종료] --> |엔터키 입력| C[게임 메뉴]
    C --> |선택| D[게임 시작]
    C --> |선택| E[옵션: 미구현]
    C --> |선택| K[게임 종료]
```

2. **인 게임 씬**

:  튜토리얼 대화 시작 -> 플레이어 이동 -> 적 조우 -> 
 적이 플레이어 발견 -> 
적 플레이어 추격 -> 적이 플레이어 공격 성공 -> 처치 컷신 연출 -> 게임오버 메뉴 
다시시작 
처음부터 다시시작 
게임 메뉴

: 적이 플레이어 놓침/ 공격 실패 -> 적 순찰 상태로 전환  \


3. **엔딩 메뉴 씬**
: 게임 클리어 후 엔딩 장면 연출, 방향키 위 아래로 메뉴 이동, 게임 메뉴와 종료 선택

```mermaid
flowchart LR
    
    A([엔딩씬 시작]) --> B[엔딩씬 종료] --> |스페이스키 입력| C[게임 메뉴]
    C --> |선택| D[게임 메뉴]
    C --> |선택| E[게임 종료]
   
```

### 1.3 만족했던 부분과 부족했던 부분
- 만족했던 부분:
1. 게임 인트로 씬 연출 
2. 플레이어/적 넉다운 연출
3. 발걸음, 공격, 뒷통수 연출 씬 등의 SFX 재생


- 부족했던 부분
1. 적 AI State 전환 
2. 적의 장애물 우회 기능의 미흡 (벽 끼임 현상)
3. 적이 플레이어 추격 시 재생되는 음악의 1회성 사용
4. 맵 디자인 부분에서 LDTK 사용하지 않고, 타일맵 단순 구현
5. 플레이어의 애니메이션 기반 공격 시 즉시 공격하지 않았음 


### 1.4 첫 게임 후의 피드백
1. Watchman 과 Ratman 의 보스 패턴이 유사한데, 
Ratman 의 쥐가 죽었을 때의 보스가 받는 이점이 생기면 좋겠다 (예를 들면, 쥐가 죽을 때마다 스피드가 빨라지는 )

2. 맵 장애물 구조의 콜라이더 디테일이 부족함, 시각적으로는 지나갈수있는 부분이 단순 콜라이더 적용으로 지나가지 못함
